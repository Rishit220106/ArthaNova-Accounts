# ArthaNova Accounts

> A full-stack accounting services and client enquiry management platform built for ArthaNova Accounts, an ACCA-led professional accounting practice serving clients across the UK, US, and Australia.

🌐 **Live Website:** https://arthanovaccounts.com

---

## Overview

ArthaNova Accounts is a production-ready full-stack web platform developed for a professional accounting practice.

The platform combines a modern, responsive corporate website with a backend-powered client enquiry management system, protected administrative APIs, automated email notifications, SEO infrastructure, and privacy/data-protection controls.

The goal was to create more than a static business website — the system provides a foundation for managing client enquiries and operating the firm's digital presence securely.

### 📩 Client Enquiry Management

Visitors can submit consultation enquiries through the website.

The system captures relevant enquiry information and sends it to the backend for processing and storage.
